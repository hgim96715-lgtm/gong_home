## 문제 분석 & 설계 (Code Before Think)

> 명예의 전당 목록의 점수의 개수 `k`, 1일부터 마지막 날까지 출연한 가수들의 점수인 `score`가 주어졌을 때, 매일 발표된 명예의 전당의 최하위 점수를 return하는 solution 함수를 완성해주세요.

1. **입/출력 분석:** (무엇을 받고, 무엇을 돌려주는가?)
    - **Input**: `k`: 명예의 전당에 유지할 점수의 개수 , `score`: 1일부터 마지막 날까지 출연한 가수들의 점수 리스트
    - **Output**: 매일 발표되는 명예의 전당 최하위 점수를 담은 리스트
2. **핵심 로직:** (어떤 자료구조나 흐름을 쓸 것인가?)
	- 리스트의 길이가 `k`보다 크면 가장 낮은 점수를 제거한다.
	- 현재 명예의 전당에서 가장 낮은 점수, 즉 리스트의 마지막 값을 `answer`에 추가한다.
3. **사용할 함수/라이브러리:**
	- `list.append()`
	- `list.sort(reverse=True)`
	- `list.pop()`
---
## ✅ 정답 코드 (Solution)

```python
def solution(k, score):
    answer = []
    rever=[]
    for s in score:
        rever.append(s)
        rever.sort(reverse=True)
        if len(rever) > k:
            rever.pop()
        # print(rever,rever[-1])
        answer.append(rever[-1])
    return answer
```

## 오답 노트 & 배운 점 (Retrospective)

-  **내가 실수한 부분 (Syntax/Logic):**
    - 처음에는 `score[i:i+k]`처럼 현재 위치부터 k개의 점수를 잘라서 사용하려고 했다.
    - 하지만 이 문제는 앞으로 나올 점수를 보는 것이 아니라, **지금까지 나온 점수 중 상위 k개**를 관리해야 하는 문제였다.
-  **새로 알게 된 함수/메서드:**
	- `pop()`은 리스트의 마지막 요소를 제거
	- 정렬된 리스트에서 `[-1]`을 사용하면 가장 마지막 값, 즉 현재 명예의 전당의 최하위 점수를 구할 수 있다.
	- `min()`을 사용하면 리스트에서 가장 작은 값을 바로 구할 수 있다.
	- `remove()`를 사용하면 특정 값을 리스트에서 제거할 수 있다
