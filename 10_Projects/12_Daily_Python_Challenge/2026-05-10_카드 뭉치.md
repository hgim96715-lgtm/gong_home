## 문제 분석 & 설계 (Code Before Think)

> 문자열로 이루어진 배열 `cards1`, `cards2`와 원하는 단어 배열 `goal`이 매개변수로 주어질 때, `cards1`과 `cards2`에 적힌 단어들로 `goal`를 만들 있다면 "Yes"를, 만들 수 없다면 "No"를 return하는 solution 함수를 완성해주세요.

1. **입/출력 분석:** (무엇을 받고, 무엇을 돌려주는가?)
    - **Input**: `cards1`: 첫 번째 카드 뭉치의 단어 배열, `cards2`: 두 번째 카드 뭉치의 단어 배열, `goal`: 만들고 싶은 단어 배열
    - **Output**: `goal`을 만들 수 있으면 `"Yes"` 만들 수 없으면 `"No"`
2. **핵심 로직:** (어떤 자료구조나 흐름을 쓸 것인가?)
	- 현재 단어가 `cards1[i]`와 같으면 `i += 1`
	- 현재 단어가 `cards2[j]`와 같으면 `j += 1`
3. **사용할 함수/라이브러리:**
	- 인덱싱 `cards1[i]`, `cards2[j]`

---
## ✅ 정답 코드 (Solution)

```python
def solution(cards1, cards2, goal):
    i=0
    j=0
    for g in goal:
        if i<len(cards1) and cards1[i]==g:
            i+=1
        elif j < len(cards2) and cards2[j]==g:
            j+=1
        else:
            return 'No'
    return 'Yes'
```

## 오답 노트 & 배운 점 (Retrospective)

-  **내가 실수한 부분 (Syntax/Logic):**
    - 처음에는 예시 입력에 맞춰서 직접 문자열을 이어 붙이는 방식으로 풀려고 했다.
    - `i == j`를 기준으로 `"Yes"` / `"No"`를 판단하는 것이 아니다.
    - `i`와 `j`는 각각 `cards1`, `cards2`에서 사용한 카드 개수를 의미
-  **새로 알게 된 함수/메서드:**
	- `pop(0)` 리스트의 첫 번째 원소를 꺼내면서 삭제할 때 사용

## 더 나은 풀이 (Pythonic Code)

> 다른 사람의 풀이나, 더 간결한 코드(리팩토링)가 있다면?


```python
# 다른 사람의 풀이나, 더 간결한 코드(리팩토링)가 있다면?
def solution(cards1, cards2, goal):
    for g in goal:
        if len(cards1) > 0 and g == cards1[0]:
            cards1.pop(0)       
        elif len(cards2) >0 and g == cards2[0]:
            cards2.pop(0)
        else:
            return "No"
    return "Yes"
```
