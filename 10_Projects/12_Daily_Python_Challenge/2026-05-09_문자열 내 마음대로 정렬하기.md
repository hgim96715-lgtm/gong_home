## 문제 분석 & 설계 (Code Before Think)

> 문자열로 구성된 리스트 strings와, 정수 n이 주어졌을 때, 각 문자열의 인덱스 n번째 글자를 기준으로 오름차순 정렬하려 합니다. 
> 예를 들어 strings가 ["sun", "bed", "car"]이고 n이 1이면 각 단어의 인덱스 1의 문자 "u", "e", "a"로 strings를 정렬합니다.

1. **입/출력 분석:** (무엇을 받고, 무엇을 돌려주는가?)
    - **Input**: 문자열 리스트 `strings`, 기준 인덱스 정수 `n`
    - **Output**: `n`번째 문자를 기준으로 오름차순 정렬된 문자열 리스트
2. **핵심 로직:** (어떤 자료구조나 흐름을 쓸 것인가?)
	- `strings` 리스트 전체를 정렬
	- 정렬 기준은 각 문자열의 `n`번째 문자
	- `n`번째 문자가 같은 경우에는 문자열 전체를 기준으로 사전순 정렬
3. **사용할 함수/라이브러리:**
	- `sorted()`
	- `lambda`

---
## ✅ 정답 코드 (Solution)

```python
def solution(strings, n):
    answer = []
    answer = sorted(strings, key=lambda s: (s[n], s))
    return answer
```

## 오답 노트 & 배운 점 (Retrospective)

-  **내가 실수한 부분 (Syntax/Logic):**
    - `lambda s: s[n]`에서 `s`는 한 글자이므로, `n = 1`일 때 `s[1]`을 접근하면 `IndexError: string index out of range`가 발생할 수 있다.
    - `sorted()`는 원본을 직접 바꾸지 않고 정렬된 새 리스트를 반환하므로, 결과를 변수에 저장하거나 바로 `return`해야 한다.
