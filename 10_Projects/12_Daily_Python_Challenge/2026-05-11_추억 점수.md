## 문제 분석 & 설계 (Code Before Think)

> 그리워하는 사람의 이름을 담은 문자열 배열 `name`, 각 사람별 그리움 점수를 담은 정수 배열 `yearning`, 각 사진에 찍힌 인물의 이름을 담은 이차원 문자열 배열 `photo`가 매개변수로 주어질 때, 사진들의 추억 점수를 `photo`에 주어진 순서대로 배열에 담아 return하는 solution 함수를 완성해주세요.

1. **입/출력 분석:** (무엇을 받고, 무엇을 돌려주는가?)
    - **Input**: `name`: 그리워하는 사람들의 이름이 담긴 리스트 ,`yearning`: `name`에 있는 사람들의 그리움 점수가 담긴 리스트, `photo`: 각 사진에 찍힌 사람들의 이름이 담긴 2차원 리스트
    - **Output**: 각 사진마다 등장한 사람들의 그리움 점수를 합산한 결과 리스트
2. **핵심 로직:** (어떤 자료구조나 흐름을 쓸 것인가?)
	- `name`과 `yearning`은 같은 인덱스끼리 짝이므로 딕셔너리로 변환
	- 딕셔너리에 없는 사람은 그리움 점수가 없으므로 `0`점으로 처리
3. **사용할 함수/라이브러리:**
	- `zip(name, yearning)`
	- `get(key, default)`

---
## ✅ 정답 코드 (Solution)

```python
def solution(name, yearning, photo):
    answer = []
    score = dict(zip(name, yearning))
    # print(score)
    for phot in photo:
        total=0
        for ph in phot:
            total+=score.get(ph,0)
        answer.append(total)
    return answer
```

## 더 나은 풀이 (Pythonic Code)

> 다른 사람의 풀이나, 더 간결한 코드(리팩토링)가 있다면?

>더 간결하게 작성하면 `sum()`과 리스트 컴프리헨션을 사용할 수 있다.

```python
# 다른 사람의 풀이나, 더 간결한 코드(리팩토링)가 있다면?
def solution(이름, 점수, 사진):
    return [sum(점수[이름.index(j)] for j in i if j in 이름) for i in 사진]
```
