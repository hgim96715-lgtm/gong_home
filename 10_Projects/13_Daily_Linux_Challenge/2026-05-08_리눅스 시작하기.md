## 📌 랩 목표

리눅스 터미널의 기본 사용법을 익히고, 가장 기초적인 명령어들을 입력하며 시스템과 소통하는 방법을 실습합니다.

### 🔷 섹션 1 — 터미널과의 첫 만남

**개념 요약**

- **`echo` 명령어:** 입력한 문자열이나 텍스트를 터미널 화면에 그대로 출력(메아리)해 주는 가장 기본적인 명령어입니다.
- 화면에 메시지를 띄우거나, 셸 스크립트 작성 시 사용자에게 진행 상황을 알려줄 때 주로 사용합니다.

**명령어 / 문법**

```bash
echo "Hello LabEx"
```

**실습 메모**

나중에 자동화 스크립트를 만들 때 `echo "백업 시작..."`과 같이 안내 메시지를 띄우는 용도로 감초처럼 쓰입니다.

### 🔷 섹션 2 — 시간과 날짜의 마법

**개념 요약**

- 시스템의 현재 시간과 날짜를 확인하거나 달력을 출력하는 명령어입니다.
- **`date`:** 현재 시스템의 연, 월, 일, 시간, 요일을 출력합니다.
- **`cal`:** 이번 달의 달력을 터미널에 직관적으로 보여줍니다. 뒤에 연도(예: 2026)를 붙이면 해당 연도의 전체 달력을 볼 수 있습니다.

**명령어 / 문법**

```bash
date
cal
cal 2026
```

**실습 메모**

마우스가 없는 서버 환경에서는 `date` 명령어가 아주 중요합니다. 서버의 시간이 어긋나 있으면 로그 기록 시간이 꼬이거나 예약된 작업이 엉뚱한 시간에 실행될 수 있으므로, 본격적인 작업 전 서버 시간을 체크하는 좋은 습관을 들여보세요.

### 🔷 섹션 3 — 계산기 마법

**개념 요약**

- **`expr` 명령어:** 터미널을 훌륭한 사칙연산 계산기로 변신시켜 주는 명령어입니다. 더하기(`+`), 빼기(`-`), 곱하기(`*`), 나누기(`/`)를 지원합니다.
- **주의사항 (매우 중요):** 숫자와 연산자 사이에는 반드시 띄어쓰기(공백)가 있어야 합니다.
- 더 복잡한 수학 계산(예: 소수점, 제곱근)이 필요하다면 `bc`나 `python` 같은 도구를 사용하는 것이 좋습니다.

**명령어 / 문법**

```bash
expr 5 + 3
expr 2026 - 2025
expr 24 * 7 # 168
expr 60 / 5
```

**실습 메모**

리눅스에서 '띄어쓰기'는 단순한 빈칸이 아니라 "이것과 저것은 별개다"라는 것을 시스템에 알려주는 아주 중요한 구분자입니다. `expr 5+3`이라고 붙여 쓰면 5 더하기 3이 아니라 '5+3'이라는 하나의 글자로 인식해 버리니 꼭 주의하세요!

### 🔷 섹션 4 — 텍스트로 즐기기

**개념 요약**

- **`figlet` 명령어:** 평범한 텍스트를 크고 멋진 ASCII 아트(문자 그림)로 변환해 주는 재미있는 도구입니다.
- **옵션 사용 (`-f`):** 명령어 뒤에 `-f` 옵션을 붙이고 폰트 이름(예: `slant`)을 적어주면 글자가 기울어지는 등 다양한 스타일을 적용할 수 있습니다.
- (참고) `man figlet`을 입력하면 이 명령어의 자세한 설명서(매뉴얼)를 열어볼 수 있습니다.

**명령어 / 문법**

```bash
figlet "LabEx"
figlet -f slant "Hong"
```

**실습 메모**

단순히 재미를 위한 도구 같지만, 실무에서도 많이 쓰입니다. 엔지니어들이 서버에 접속했을 때 "현재 운영(Production) 서버에 접속하셨습니다!" 같은 경고문을 크고 눈에 띄게 만들어 실수로 다른 서버를 건드리지 않도록 예방하는 용도로 찰떡입니다.

### 🔷 섹션 5 — 깔끔하게 정리하기

**개념 요약**

- **`clear` 명령어:** 명령어와 실행 결과로 가득 차서 복잡해진 터미널 화면을 새 창처럼 깨끗하게 지워줍니다.
- 실제로 데이터가 삭제되는 것은 아니며, 화면을 위로 쑥 밀어 올려 시야를 정리해 주는 역할을 합니다. (스크롤을 올려보면 이전 작업 내역이 그대로 남아있습니다.)

**명령어 / 문법**

```bash
clear
```

**실습 메모**

실무 꿀팁 하나 방출합니다! 명령어 입력 없이 단축키 `Ctrl + L`을 누르면 똑같이 화면이 깔끔하게 정리됩니다.
