## 📌 랩 목표

- 리눅스에서 명령어의 종류를 구분할 수 있다.
- 내장 명령어와 외부 명령어의 차이를 이해한다.
- `type`, `--help`, `man`, `apropos` 명령어를 사용하여 도움말을 찾을 수 있다.
- 모르는 명령어가 나왔을 때 스스로 사용법을 확인하는 방법을 익힌다.
- 특정 작업과 관련된 명령어를 검색하는 방법을 익힌다.

### 🔷 섹션 1 — 내장 명령어와 외부 명령어 이해하기

**개념 요약**

- 도움말을 찾는 구체적인 방법에 앞서, 리눅스의 **내장 명령어 Built-in** 와 **외부 명령어 External** 의 차이점을 먼저 알아봅니다.
- **내장 명령어**는 쉘 프로그램 내부에 포함된 명령어입니다.
- `cd is a shell builtin`은 `cd` 명령어가 쉘 프로그램 내부에 포함되어 있다는 뜻입니다.
- 외부 명령어는 주로 `/bin`, `/usr/bin` 같은 디렉토리에 위치합니다.
- `ls is aliased to 'ls --color=tty'`는 `ls`를 입력했을 때 실제로는 `ls --color=tty`가 실행된다는 의미입니다.
- `type` 명령어를 사용하면 특정 명령어가 내장 명령어인지, 별칭인지, 외부 명령어인지 확인할 수 있습니다.

**명령어 / 문법**

```bash
type cd 
type ls
```

**실습 메모**

`type cp`, `type grep`처럼 외부 명령어를 확인하면 실행 파일 경로가 출력된다.
명령어가 실제로 어떻게 실행되는지 확인할 때 `type`을 사용하면 좋다.

### 🔷 섹션 2 — --help 옵션 사용하기

**개념 요약**

- 대부분의 리눅스 명령어는 명령어 사용법에 대한 빠른 요약을 제공하는 --help 옵션을 지원합니다.
-  대괄호 `[]`는 선택 사항을 의미합니다. 
- 따라서 `[OPTION]...`은 옵션을 하나도 쓰지 않거나 여러 개 사용할 수 있음을 뜻하며,
- `[FILE]...`은 대상 파일이나 디렉토리를 지정할 수 있음을 의미합니다.
- 점 세 개 `...`은 여러 개를 사용할 수 있다는 뜻입니다.
- 예를 들어 `ls [OPTION]... [FILE]...`은 `ls` 명령어 뒤에 옵션과 파일명을 선택적으로 여러 개 입력할 수 있다는 의미입니다.
- 출력 내용이 너무 길어서 터미널 하단에 콜론 `:` 이 나타난다면, `Space` 바를 눌러 다음 내용을 볼 수 있습니다.
- 도움말 화면에서 나가고 싶다면 `q`를 눌러 종료하고 프롬프트로 돌아올 수 있습니다.

**명령어 / 문법**

```bash
ls --help
cp --help
```

**실습 메모**

- `--help`는 빠른 참고용이고, 더 자세한 설명은 `man` 명령어를 사용한다.

### 🔷 섹션 3 — man 명령어로 상세 매뉴얼 탐색하기

**개념 요약**

- `man` 명령어는 명령어에 대한 전체 매뉴얼 문서를 보여줍니다.
- `--help`보다 훨씬 더 상세한 정보를 제공합니다.
- 위/아래 화살표 키를 사용하여 한 줄씩 스크롤합니다.
- `Space` 바를 눌러 한 페이지씩 앞으로 이동합니다.
- `b` 키를 눌러 한 페이지씩 뒤로 이동합니다.
- `/` 키를 누른 후 단어를 입력하면 해당 단어를 문서에서 검색할 수 있습니다.
- 예를 들어 `/sort`라고 입력하면 `sort`라는 단어를 찾습니다.
- `n` 키를 누르면 검색한 단어의 다음 검색 결과로 이동합니다.
- `N` 키를 누르면 검색한 단어의 이전 검색 결과로 이동합니다.
- 탐색을 마쳤다면 `q`를 눌러 매뉴얼 페이지를 종료하고 프롬프트로 돌아옵니다.

**명령어 / 문법**

```bash
man ls
man grep
```

**실습 메모**

- `man grep`을 실행하면 문자열 검색 명령어인 `grep`의 사용법을 자세히 확인할 수 있다.
- 매뉴얼 안에서 특정 옵션이나 단어를 찾고 싶을 때 `/검색어`를 사용한다.

### 🔷 섹션 4 — apropos 로 관련 명령어 찾기

**개념 요약**

- apropos 명령어는 특정 키워드와 관련된 명령어를 찾는 데 도움을 줍니다
- 무엇을 해야 할지는 알지만 어떤 명령어를 써야 할지 모를 때 매우 유용합니다.
- `apropos`는 매뉴얼 페이지의 이름과 설명에서 키워드를 검색합니다.
- 검색 결과가 너무 많을 경우 `grep`과 함께 사용하여 원하는 결과만 걸러낼 수 있습니다.

**명령어 / 문법**

```bash
apropos password
apropos file
apropos file | grep create
```

**실습 메모**

- `apropos file | grep create`는 파일 관련 명령어 중에서 `create`가 포함된 결과만 필터링한다.
- 명령어 이름이 기억나지 않을 때 `apropos`를 사용하면 좋다.
