## 📌 랩 목표

- 리눅스에서 파일을 삭제, 복사, 이동하는 방법을 익힌다.
- `rm`, `cp`, `mv` 명령어의 기본 사용법을 이해한다.
- 절대 경로와 홈 디렉토리 기호 `~`를 사용하여 파일 위치를 지정할 수 있다.
- 파일을 다른 디렉토리로 옮기거나 복사하는 작업을 실습한다.
- 파일 이름 변경과 디렉토리 관련 작업도 함께 익힌다.

---

## 📖 학습 내용


---

### 🔷 섹션 1 — 파일 삭제

**개념 요약**

- `rm` 명령어는 파일을 삭제할 때 사용하는 명령어 `rm`은 remove의 줄임말입니다.
- 리눅스에서 `rm`으로 삭제한 파일은 일반적으로 휴지통으로 이동하지 않고 바로 삭제됩니다
- 따라서 `rm` 명령어를 사용할 때는 삭제할 파일 경로를 정확히 확인해야 합니다.
- `~`는 현재 사용자의 홈 디렉토리를 의미합니다.

**명령어 / 문법**

```bash
rm ~/project/challenge1/challenge1.txt
```

**실습 메모**

- 삭제 전에는 파일 이름과 경로를 반드시 확인해야 한다.
- 실수로 중요한 파일을 삭제하지 않도록 주의한다.

---

### 🔷 섹션 2 — 파일 복사

**개념 요약**

- cp 명령어를 사용하여 리눅스 시스템에서 파일을 복사해 보겠습니다.
- `cp`는 copy의 줄임말입니다.
- 기본 형식은 `cp 원본파일 복사할위치`입니다.

**명령어 / 문법**

```bash
cp ~/project/challenge2/challenge2.txt ~/project/challenge1/
```

**실습 메모**

- `cp` 명령어는 원본 파일을 삭제하지 않고 복사본을 만든다.

---

### 🔷 섹션 3 — 파일 이동

**개념 요약**

- `mv` 명령어를 사용하여 리눅스 시스템에서 파일을 이동할 수 있습니다.
- 기본 형식은 `mv 이동할파일 이동할위치`입니다.
- `cp`는 복사라서 원본이 남지만, `mv`는 이동이므로 원본 위치에 파일이 남지 않습니다.

**명령어 / 문법**

```bash
mv ~/project/challenge3/challenge3.txt ~/project/challenge1/
```

**실습 메모**

- 이동 후 원래 디렉토리에는 파일이 남아 있지 않다.
