### 🔷 섹션 1 — 리눅스 디렉토리 구조 탐색하기

**개념 요약**

- 리눅스 파일 시스템은 `/` 루트 디렉토리에서 시작한다.
- `pwd`는 현재 내가 있는 위치를 확인할 때 사용
- `ls`는 디렉토리 안의 파일과 폴더를 확인할 때 사용
- `cd`는 다른 디렉토리로 이동할 때 사용
- `~`는 현재 사용자의 홈 디렉토리를 의미
- `/home`, `/etc`, `/bin`은 리눅스에서 자주 사용하는 주요 디렉토리
- `tree` 명령어는 디렉토리 구조를 나무 모양으로 보여준다.
- `ls -l`은 디렉토리 내용을 자세한 형식으로 보여준다.

**명령어 / 문법**

```bash
pwd
tree / 
ls /home
ls /etc
ls /bin

cd / 
ls -l

cd ~
pwd
```

**실습 메모**

- `/etc`에는 설정 파일이 있다.
- `/bin`에는 기본 실행 명령어들이 있다.
- `/home`에는 사용자별 홈 디렉토리가 있다.
- `/`는 리눅스의 최상위 디렉토리이다.

### 🔷 섹션 2 — 경로와 탐색의 이해

**개념 요약**

- 절대 경로는 `/`부터 시작하는 전체 경로
- 상대 경로는 현재 위치를 기준으로 이동하는 경로
- `mkdir -p`는 중간 디렉토리까지 한 번에 생성할 때 사용
-  `..`은 상위 디렉토리를 의미한다.
- `cd -`는 이전에 있던 디렉토리로 이동한다.
- `cd`만 입력하면 홈 디렉토리로 이동한다.

**명령어 / 문법**

```bash
mkdir -p ~/project/practice/subdirectory
cd ~/project/practice/subdirectory 
pwd

cd ..
pwd

cd /home/labex/project/practice/subdirectory 
pwd

cd ~ # 홈 디렉토리로 이동 
pwd 
cd - # 이전 디렉토리로 이동 
pwd 
cd # 홈 디렉토리로 이동하는 또 다른 방법 
pwd
```

**실습 메모**

- `/home/labex/project`처럼 `/`로 시작하면 절대 경로
- `~/project`는 홈 디렉토리를 기준으로 한 경로
- `cd ..`은 한 단계 위로 이동할 때 사용
- `cd -`는 바로 이전 위치로 돌아갈 때 유용

### 🔷 섹션 3 — 파일 및 디렉토리 생성과 관리

**개념 요약**

-  `mkdir`은 디렉토리를 생성한다.
- `touch`는 빈 파일을 생성한다.
- `echo`는 텍스트를 출력한다.
- `>`는 내용을 파일에 저장하며, 기존 내용은 덮어쓴다.
- `>>`는 기존 내용을 유지하면서 뒤에 내용을 추가한다.
- `cat`은 파일 내용을 확인할 때 사용한다.
- `tree`는 디렉토리 구조를 보기 좋게 출력한다.

**명령어 / 문법**

```bash
cd ~/project
mkdir dir1 dir2 dir3 
ls

touch file1.txt 
ls -l file1.txt # -rw-rw-r-- 1 labex labex 0 May 13 07:17 file1.txt

echo "Hello, Linux" > file2.txt 
cat file2.txt

echo "This is a new line." >> file2.txt 
cat file2.txt

mkdir -p nested/structure/example 
tree nested
```

**실습 메모**

- `mkdir dir1 dir2 dir3`처럼 여러 디렉토리를 한 번에 만들 수 있다.
- `touch`로 만든 빈 파일은 크기가 0바이트이다.
- `>`는 덮어쓰기, `>>`는 이어쓰기이다.

### 🔷 섹션 4 — 파일 복사, 이동 및 이름 변경

**개념 요약**

- `cp`는 파일이나 디렉토리를 복사
- `mv`는 파일이나 디렉토리를 이동
- `mv`는 파일 이름을 변경할 때도 사용
- 파일 복사는 원본이 남는다.
- 파일 이동은 원본 위치에서 사라지고 대상 위치로 옮겨진다.
- 디렉토리를 복사할 때는 `cp -r` 옵션을 사용

**명령어 / 문법**

```bash
cp file1.txt dir1/
ls dir1

cp file2.txt dir2/file2_copy.txt 
ls dir2

mv file1.txt dir3/
ls
ls dir3

mv dir3/file1.txt dir3/renamed_file.txt 
ls dir3

cp -r nested dir1/ 
tree dir1
```

**실습 메모**

- `cp 원본 대상위치` 형태로 사용한다.
- `mv 원본 대상위치` 형태로 사용한다.
- 같은 위치에서 `mv 기존이름 새이름`을 사용하면 이름 변경이 된다.
- 디렉토리 복사는 `cp -r`을 사용한다.

### 🔷 섹션 5 — 파일 내용 보기 및 편집

**개념 요약**

- `cat`은 파일 전체 내용을 확인한다.
- `nl`은 줄 번호와 함께 파일 내용을 출력한다.
- `head`는 파일의 앞부분을 보여준다.
- `tail`은 파일의 뒷부분을 보여준다.
- `nano`는 터미널에서 사용하는 간단한 텍스트 편집기이다.
- `<< EOF`는 여러 줄의 내용을 한 번에 파일에 입력할 때 사용한다.

**명령어 / 문법**

```bash
cat << EOF > multiline.txt 
Line 1: Hello, Linux 
Line 2: This is a multiline file. 
Line 3: Created using a here-document. 
EOF

cat multiline.txt
nl multiline.txt
head -n 2 multiline.txt
tail -n 1 multiline.txt
nano multiline.txt
cat multiline.txt
```

**실습 메모**

- `nano`에서 저장은 `Ctrl + O`, 종료는 `Ctrl + X`이다.

### 🔷 섹션 6 — 리눅스에서 파일 찾기

**개념 요약**

- `find`는 조건에 맞는 파일이나 디렉토리를 찾는다.
- `.`은 현재 디렉토리를 의미한다.
- `~`는 홈 디렉토리를 의미한다.
- `-name`은 파일 이름으로 검색할 때 사용한다.
- `-size`는 파일 크기로 검색할 때 사용한다.
- `-mtime`은 수정 시간으로 검색할 때 사용한다.
- `which`는 실행 명령어의 실제 위치를 찾는다.

**명령어 / 문법**

```bash
find . -name "*.txt"

echo "This is a test file" > test.txt 
find . -name "*.txt"

sudo find / -name "passwd"
find ~ -size +1M
find ~ -mtime -1

which python
which python3
```

**실습 메모**

- `sudo find / -name "passwd"`는 루트 디렉토리 전체에서 `passwd` 파일을 찾는다.
- `find ~ -size +1M`은 홈 디렉토리에서 1MB보다 큰 파일을 찾는다.
- `find ~ -mtime -1`은 최근 24시간 안에 수정된 파일을 찾는다.
