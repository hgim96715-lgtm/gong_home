### 🔷 섹션 1 — 터미널 이해 및 실행하기

**개념 요약**

- 터미널은 명령어를 입력해서 컴퓨터를 조작하는 프로그램입니다.
- 마지막 줄에 보이는 입력 대기 상태를 **프롬프트(prompt)** 라고 합니다.
- 프롬프트는 보통 `$` 기호로 끝나며, 이곳에 명령어를 입력하고 Enter를 누르면 실행됩니다.
-  `$` 앞부분은 현재 사용자나 위치 정보를 보여준다.
- `$` 뒤에 직접 명령어를 입력한다.

**명령어 / 문법**

```bash
labex:project/ $ 
```

### 🔷 섹션 2 — 파일 시스템 탐색하기

**개념 요약**

- 리눅스에서는 폴더를 **디렉토리(directory)** 라고 부릅니다.
- 현재 내가 어느 위치에 있는지 확인할 때는 `pwd` 명령어를 사용합니다.
- `pwd`는 현재 작업 중인 디렉토리의 전체 경로를 출력합니다.
- `cd`는 **change directory**의 약자로, 디렉토리를 이동할 때 사용합니다.
- `~`는 홈 디렉토리를 의미합니다.
- `/`는 파일 시스템의 가장 위에 있는 최상위 루트 디렉토리입니다.
- `ls`는 **list**의 약자로, 현재 디렉토리에 있는 파일과 디렉토리 목록을 보여줍니다.
- 리눅스에서는 디렉토리를 구분할 때 `\`가 아니라 `/`를 사용합니다.  또한 파일명과 디렉토리명은 대소문자를 구분합니다.

**명령어 / 문법**

```bash
pwd
cd ~
cd project
ls
```

**실습 메모**

리눅스에서는 `project`, `Project`, `PROJECT`를 모두 다른 이름으로 인식한다.

### 🔷 섹션 3 — 파일 및 디렉토리 생성하기

**개념 요약**

- 새 디렉토리를 만들 때는 `mkdir` 명령어를 사용합니다.
- `mkdir`은 **make directory**의 약자입니다.
- 빈 파일을 만들 때는 `touch` 명령어를 사용합니다.  
- 파일이 존재하지 않으면 새 빈 파일을 만들고, 이미 존재하는 파일이라면 수정 시간을 업데이트합니다.
- 파일에 내용을 저장할 때는 `echo`와 리다이렉션 기호 `>`를 사용할 수 있습니다.
- 파일 내용을 확인할 때는 `cat` 명령어를 사용합니다.

**명령어 / 문법**

```bash
mkdir linux_practice
cd linux_practice
touch hello.txt
ls
echo "Hello, Linux" > hello.txt
cat hello.txt
```

**실습 메모**

### 🔷 섹션 4 — 와일드카드 사용하기

**개념 요약**

- 와일드카드는 여러 파일을 한 번에 선택하거나 찾을 때 사용하는 특수 문자입니다.
- `*`는 글자 수와 상관없이 모든 문자와 일치합니다.
- 예를 들어 `*.txt`는 `.txt`로 끝나는 모든 파일을 의미합니다.
- `?`는 정확히 한 글자와 일치합니다.
- 예를 들어 `file?.txt`는 `file1.txt`, `file2.txt`처럼 한 글자만 다른 파일과 일치합니다.
- `[abc]`는 괄호 안에 있는 문자 중 하나와 일치합니다.
- 예를 들어 `file[123].txt`는 `file1.txt`, `file2.txt`, `file3.txt`와 일치합니다
- `{1..5}`는 숫자 범위를 자동으로 생성할 때 사용할 수 있습니다.

**명령어 / 문법**

```bash
touch file1.txt file2.txt file3.txt
ls *.txt
touch note_{1..5}.txt
ls note*
```

**실습 메모**

`touch note_{1..5}.txt`를 사용하면 `note_1.txt`부터 `note_5.txt`까지 한 번에 생성

### 🔷 섹션 5 — 기초 파일 조작

**개념 요약**

- 파일을 복사할 때는 `cp` 명령어를 사용합니다.   `cp`는 **copy**의 약자입니다.
- `{bash}cp 원본파일 대상파일`
- 파일을 이동하거나 이름을 바꿀 때는 `mv` 명령어를 사용합니다.  `mv`는 **move**의 약자입니다.
- `..`은 현재 위치보다 한 단계 위에 있는 상위 디렉토리를 의미합니다.
- 파일을 삭제할 때는 `rm` 명령어를 사용합니다. `rm`은 **remove**의 약자입니다.
- 리눅스에서 `rm`으로 삭제한 파일은 휴지통으로 이동하지 않고 즉시 삭제될 수 있으므로 주의해야 합니다.

**명령어 / 문법**

```bash
cp hello.txt hello_copy.txt
mv hello_copy.txt ..
rm file1.txt
ls
ls ..
```

**실습 메모**

- `rm` 명령어는 되돌리기 어렵기 때문에 삭제 전에 파일명을 꼭 확인해야 한다.

### 🔷 섹션 6 — 커맨드라인 단축키 활용하기

**개념 요약**

- 리눅스 터미널에는 명령어 입력을 더 빠르고 편하게 해주는 단축키가 있습니다.
- `Tab` 키는 자동 완성 기능을 제공합니다.
- 파일명이나 디렉토리명을 일부만 입력한 뒤 `Tab`을 누르면 가능한 이름으로 자동 완성됩니다.
- 위쪽 화살표 키 `↑`는 이전에 입력했던 명령어를 다시 불러옵니다.
- 반복해서 입력해야 하는 명령어가 있을 때 유용합니다.
- `tail -f /dev/null`은 터미널 세션을 계속 실행 상태로 유지할 때 사용할 수 있습니다.

**명령어 / 문법**

```bash
cat h
tab으로 cat hello.txt
tail -f /dev/null
```

**실습 메모**

### 🔷 섹션 7 — 도움말 얻기

**개념 요약**

- 리눅스 명령어의 사용법이 기억나지 않을 때는 도움말을 확인할 수 있습니다.
- 간단한 사용법을 빠르게 확인하고 싶을 때는 `--help` 옵션을 사용합니다.
- 예를 들어 `ls --help`를 입력하면 `ls` 명령어에서 사용할 수 있는 옵션 목록을 확인할 수 있습니다.
- 더 자세한 설명이 필요할 때는 `man` 명령어를 사용합니다.
- `man`은 **manual**의 약자로, 명령어의 공식 설명서를 보여줍니다.
- 예를 들어 `man ls`는 `ls` 명령어의 자세한 사용법을 보여줍니다.
- 이전에 입력했던 명령어 기록을 보고 싶을 때는 `history` 명령어를 사용합니다.

**명령어 / 문법**

```bash
ls --help
man ls
man cp
```

**실습 메모**

- `history`를 사용하면 이전에 입력했던 명령어 목록을 다시 확인할 수 있다.
- 명령어가 기억나지 않을 때 바로 검색하기보다 `--help`와 `man`을 먼저 확인하는 습관을 들이면 좋다.
